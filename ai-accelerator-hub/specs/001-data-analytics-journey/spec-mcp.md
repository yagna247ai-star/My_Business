# Specification

## Requirements

AI-powered data analytics journey for entry-level learners, 45 days, 9 modules, source: 45-Day Data Analytics syllabus PDF. Modules: M1 Data Analytics Fundamentals (Days 1-4); M2 SQL for Data Analytics (Days 5-11); M3 Python Fundamentals (Days 12-16); M4 Python for Data Analytics with pandas and NumPy (Days 17-22); M5 Power BI (Days 23-27); M6 AI for Data Analytics (Days 28-31); M7 Machine Learning (Days 32-36); M8 ETL and Data Quality (Days 37-41); M9 Capstone and Industry Readiness (Days 42-45). Every day opens with a fictional MSME business problem (Sunita Stores grocery, Bright Smile Dental Clinic, Little Scholars Tuition Centre, Ganesh Micro-Credit Co-op, Ravi Textiles, Pinnacle Tools) and ends with a learner task, deliverable and answer key. Rubric: correct result 0.35, business reading 0.25, method 0.20, data checks 0.10, reflection 0.10, pass 3.0 of 5. Assessment weights: daily 20%, SQL and Python 20%, module exams 15%, Power BI 10%, capstone 25%, viva 10%. Synthetic data only, no personal identifiers, AI output must be verified against data, no advanced ML or production ETL claims. Content only: no application code in this feature. Three capstones: Retail Sales Analytics, HR Employee Analytics, Healthcare Data Analytics. Target roles: Junior Data Analyst, SQL Analyst Trainee, Python Data Analyst Trainee, Power BI Developer Trainee, Data Quality Analyst Trainee, ETL Tester Trainee, MIS Reporting Analyst.

## User Stories

As an entry-level learner, I want SQL practice on small-business problems so I can answer an owner question with a query. As an entry-level learner, I want to clean messy data in Python so I can produce a trustworthy summary. As an entry-level learner, I want a Power BI dashboard tied to an owner question so I can explain one action. As a learner, I want to use AI tools and verify their output so I do not report wrong numbers. As a learner, I want an introduction to prediction with honest metrics. As a learner, I want to validate a pipeline with reconciliation. As a learner, I want to complete a capstone and be interview-ready.
