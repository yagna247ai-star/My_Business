# Day 27 — A One-Page Morning Dashboard

> **Time:** 4 h 30 min · **Module:** M5 Power BI · **Shop:** Sunita Stores

## The problem
Every morning, Sunita wants to see four things in one place:
- Yesterday's revenue.
- The trend this month.
- Which branch is ahead.
- Which products need attention.

Sunita does not want to open five tabs. Sunita also wants to click a branch and see its products on a second page.

## The big idea
A good dashboard answers questions, in order. Like a newspaper front page: the headline first, then the details.

- **Card**: one big number. "Revenue today: ₹48,200."
- **Line chart**: a trend over time. "Is it going up?"
- **Bar chart**: compare groups. "Which branch is ahead?"
- **Table**: exact numbers. "Which products, and how much?"
- **Slicer**: a button the user clicks to choose, like a month or a branch.
- **Drill-through**: a second page you reach by right-clicking a number. The branch you picked comes with you.

**Four design rules:**
1. Every chart answers one question.
2. The title is the question, for example "Which branch is ahead this month?"
3. Use the same colours for the same things.
4. Keep it to about six visuals per page.

## Words to know
- **Visual**: any chart, card, or table on a page.
- **Drill-through**: a link that opens a detail page.
- **Publish**: send the report from Desktop to the Service, so others can see it.

## Let's solve it
Build the page in this order:
1. Three cards at the top: Revenue, Orders, Avg Order Value (from Day 26).
2. A line chart of revenue by date.
3. A bar chart of revenue by branch.
4. A table of product, revenue, and share.
5. Two slicers: month and branch.
6. A second page called "Product detail", reached by drill-through.

**Look at a bad version first.** A page with eight charts, rainbow colours, and no titles is hard to read. Ask: what question does each chart answer?

## Check yourself (trainer's answer key)
1. A slicer is a button you click. A filter works in the background.
2. About six visuals keeps the page easy to read in one glance.
3. Drill-through keeps the branch you picked. A new page would start over.
