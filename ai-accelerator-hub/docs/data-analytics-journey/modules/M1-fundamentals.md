# M1 — Data Analytics Fundamentals · Days 1–4

| | |
|---|---|
| Parent | `../00-INDEX.md` |
| Duration | 4 days (PDF Days 1–4) |
| MSMEs | Sunita Stores, Bright Smile Dental Clinic, Little Scholars Tuition Centre, Ganesh Micro-Credit Co-op |
| Tools | Paper or notes app, Excel (Windows or Mac), CSV files |

## Objective
Understand what data is, why a small business needs analytics, how data flows through an analytics job, and how the same ideas apply across domains.

## Learning outcomes
- Name the data a small business already produces, every day.
- Tell structured, semi-structured and unstructured data apart, and qualitative from quantitative.
- Describe the analytics lifecycle in order and say what goes wrong when a step is skipped.
- Read a simple CSV and an Excel sheet and say what each row and column means.

## Module assessment (15% module exam, part of the course total)
- Multiple choice (10 questions, 60% to pass): definitions, data types, lifecycle order.
- Practical (one case): given a small sales CSV, list the columns, state the grain (one row = ?) and name two quality concerns.

## Job link
Junior Data Analyst and MIS / Reporting Analyst both start with "explain what this data is and what it can and cannot tell us".
