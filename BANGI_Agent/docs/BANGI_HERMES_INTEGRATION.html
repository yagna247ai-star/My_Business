Hybrid Router — How Bangi Decides

CONFIG: hermes.mode = hybrid • hot-swappable

Keyword router in backend/bangi_agent.py:do_task(). Every branch logs to events.jsonl. Add a new skill → one new if "keyword" in p line.

DIRECT API — NO SOM
If prompt contains crm, tracker, report, campaign, reel, coach, convert, emi, market, nri, cadence, visit → calls Hermes skill Python directly. No screenshot. No model vision tokens.
SOM FALLBACK
If prompt contains job, naukri, linkedin, indeed, apply or generic desktop (“open Excel”, “fill form”) → handle_computer_use(capture/click) with numbered overlays [1][2][3].
HOW TO ADD A SKILL
Add Hermes skill file → expose one endpoint in app.py → add one keyword branch in bangi_agent.py → list it in config.yaml: hermes.routing.prefer_direct.

Architecture — C4 Container

Single FastAPI, two Hermes systems, one SOM driver. Same backend/ ships to Web (PWA), Desktop (Tauri 5MB), Mobile (Capacitor) — 95% shared.
