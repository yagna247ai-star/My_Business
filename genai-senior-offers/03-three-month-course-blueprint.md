# Offer 2 — The 3-Month GenAI Engineering Leadership Program (10–15 Yrs Track)

## 1. Naming

- **Primary:** "GenAI Engineering Leadership Program"
- Alternatives: "GenAI Architect & Leader Track" / "The GenAI Command Program"
- **Tagline:** *"You don't need another tutorial. You need a system you can own, defend, and ship."*

## 2. Positioning

For 10–15-year professionals: a 12-week senior track that **compresses the GEF C6 technical core (24 weeks) and adds the leadership layer.**

**Outcome:** a production-grade multi-agent system + an org adoption playbook. You lead GenAI delivery in your company — instead of watching juniors outpace you.

## 3. Who It's For / Not For

**FOR:** senior SWEs, engineering managers, architects, data science leads, small-company CTOs with 10–15 years of experience; Python-fluent (any level); want to lead, decide, and ship.
**NOT FOR:** beginners (point them to the full GEF C6 program), certificate-collectors, pure managers with no technical appetite.

## 4. Curriculum — 12 Weeks (mapped from GEF C6)

### Phase 1 — The Decision Layer (Weeks 1–2) · GEF Wk 1–5 compressed
- **Wk 1 — LLM reality check:** transformers in one session (GEF Wk 3 S2); prompt patterns at scale — zero/few-shot, CoT, system prompts, guardrails (GEF Wk 3 S1); evals mindset intro.
- **Wk 2 — RAG at production level:** chunking strategies (semantic, content-aware), embedding choices (OpenAI, Sentence Transformers, E5, BGE, sparse), hybrid search + reranking, Ragas evaluation (GEF Wk 4–5 + Wk 16 S1).

### Phase 2 — The Agent Layer (Weeks 3–5) · GEF Wk 10–14
- **Wk 3 — Agentic foundations:** tools, memory, guardrails; OpenAI Agents SDK — handoffs, runners, tracing (GEF Wk 11).
- **Wk 4 — LangGraph + MCP:** state machines, multi-agent teams (GEF Wk 13); FastMCP server implementation (GEF Wk 10 S2).
- **Wk 5 — LangChain workflows + agentic RAG:** intelligent routing, dynamic knowledge selection; reliability — retries, limits, error handling, LangSmith tracing (GEF Wk 14–15).

### Phase 3 — The Production Layer (Weeks 6–8) · GEF Wk 15–16 + Wk 6
- **Wk 6 — Inference economics:** vLLM/SGLang, continuous batching, KV cache, prompt caching, model routing to cheaper SLMs (GEF Wk 15 S2).
- **Wk 7 — Evals at scale:** offline vs online, LLM-as-judge, synthetic data, dataset versioning (GEF Wk 16 S1); structured-data RAG — SQL/Text2SQL, CSV, JSON (GEF Wk 6).
- **Wk 8 — Fine-tuning strategy:** LoRA/QLoRA, adapters vs full FT, when fine-tuning actually wins, serving implications (GEF Wk 16 S2).

### Phase 4 — The Multimodal Layer (Week 9) · GEF Wk 7–9 compressed
- **Wk 9 — Multimodal RAG:** CLIP/BLIP encoders, modality fusion, LanceDB (IVF-PQ, hybrid search), image/video/audio pipelines end-to-end (GEF Wk 8–9).

### Phase 5 — The Capstone (Weeks 10–11) · GEF Wk 17–24 compressed
- **Wk 10 — Capstone sprint 1:** scope + architecture review with mentor; team formation.
- **Wk 11 — Capstone sprint 2:** build the production multi-agent system (e.g., AI search engine + RAG chatbot + agent workflow); weekly 1:1 clinics.

### Phase 6 — The Leadership Layer (Week 12)
- **Wk 12 — Org adoption:** team operating model, vendor governance, risk/guardrails, ROI storytelling; **final demo day + graduation** (reuse GEF C6 demo-day format).

## 5. Delivery Format

- **Weekly rhythm:** 1 live session (2.5–3 hrs, Sat/Sun, IST + ET-friendly), 1 async lab, 1 optional 30-min architecture clinic.
- **Mentor check-ins:** 1:1 mid-program (30 min) + capstone review.
- **LMS:** reuse GEF C6 LMS + session recordings; cohort community on Slack.
- **Effort:** 6–8 hrs/week — built for time-poor leaders.
