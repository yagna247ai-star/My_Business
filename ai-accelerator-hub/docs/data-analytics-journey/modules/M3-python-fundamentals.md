## Objective
Write small, correct Python programs that use variables, conditions, loops, data structures, functions and file handling. These are the building blocks for M4.

## Learning outcomes
- Install Python, run a script, and use variables and basic types.
- Write conditionals (`if`, `elif`, `else`) and loops (`for`, `while`, `break`, `continue`).
- Choose between lists, tuples, sets and dictionaries for a given business record.
- Write functions with parameters and return values, handle exceptions, and read and write files.
